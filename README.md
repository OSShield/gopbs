# go-pbs
GoPBS is a library meant to make it easier to backup and restore data to and from PBS (Proxmox Backup Server). It provides a number of interfaces for various types of tasks.

## Credit
Credit where credit is due - I did not figure most of this out by myself. A large part of the work regarding finding the specification, optimizing the backup process, etc. was done by [@tizbac](https://github.com/tizbac), go support his work if you are able.
